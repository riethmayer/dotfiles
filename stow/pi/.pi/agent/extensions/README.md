# Pi extensions

Maintained Pi extensions use Effect 4 for typed errors, async boundaries, schema validation, and state handling. `herdr-agent-state.ts` is generated by Herdr and remains outside this package's ownership.

```sh
pnpm install
pnpm test
pnpm check
pnpm diagnostics
mise run pi:test # from the dotfiles root
```

`@effect/tsgo` patches the workspace TypeScript 7 compiler during `pnpm install`. LazyVim uses the native `tsc --lsp` server, so this workspace receives Effect diagnostics and refactors without running a second TypeScript server.
